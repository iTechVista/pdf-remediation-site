What was wrong

The original page was tagged, but every line was a plain paragraph with no headings, so a screen reader could not jump between the sections and the four examples, the header banner with the college logos was not tagged, and one embedded font had a faulty character set. veraPDF reported 1 failed check under 1 PDF/UA-1 rule.

What we fixed

The remediated file has the title as the main heading, the two rules (if you have never passed the class, once you earn a passing grade) and the four examples as headings, the list of reasons as a list, the header banner described with the Foxes mascot logo, web address and college logo, and a document title that names the college. It passes PDF/UA-1. The page looks the same as your original.
